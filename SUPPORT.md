# Get help with PROTOCOL

Found a problem or have an idea? Check the
[existing reports](https://github.com/KadenB20/PROTOCOL-Community/issues) first,
then open a new one if yours isn't there. I read reports and suggestions as time
allows, so replies may take a while.

## Reporting a problem

Include your PROTOCOL version, Windows version, what you were trying to do, and
what happened instead. If you can repeat the problem, list the steps. A screenshot
can help, but crop out personal details before uploading it.

If an update fails, keep your data folder and the backup you made before updating.
Don't reset your workspace or delete records to try to fix it.

## Installation warnings

For an installer warning or antivirus block, read
[Windows warnings](DOWNLOAD-SAFETY.md), then use the
[installation-warning form](https://github.com/KadenB20/PROTOCOL-Community/issues/new?template=installation_warning.yml).
Include the exact warning or threat name so I can investigate the right file and
security product. Leave blocked files blocked; don't disable protection or restore
a quarantined file to test it.

## Suggestions

Explain what you'd like to do and what makes it difficult at the moment. A real
example is useful. I can't promise a release date for suggestions.

## Keep personal information private

GitHub reports are public. Don't attach databases, backups, bloodwork, private
photos, passwords, or anyone else's information. For a security vulnerability,
follow the [private reporting instructions](SECURITY.md).
