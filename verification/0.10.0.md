## Windows installation checks

The installer passed automated tests in a disposable Windows environment for:

- A fresh installation and running the same-version installer again.
- Updating from 0.9.1 while keeping saved records, Vault files and earlier backups.
- Backup validation, restore, and recovery backups before database migration.
- Keeping separately stored workspace data when uninstalling the application.
- Update controls and saved preferences, without application console or page errors.

These tests cover installation and data handling, not every app feature or
Windows configuration.

## Limits and reporting

These results aren't an independent security audit or certification.
A clean scan does not prove a file is harmless or predict future detections.
SmartScreen, Smart App Control and other antivirus products can still warn or
block this unsigned release. [See the warning guide](../DOWNLOAD-SAFETY.md).

If security software reports a threat, leave it blocked and
[report the exact detection](https://github.com/KadenB20/PROTOCOL-Community/issues/new?template=installation_warning.yml).
Do not attach personal records.
