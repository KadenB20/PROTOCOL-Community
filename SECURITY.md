# Report a security problem

Please do not publish exploit details or private records in a public issue.
Use **Security → Advisories → Report a vulnerability** in this repository for a
private report. Include the affected version and a reproducible example using
made-up records. Do not send real health information or credentials.

If private reporting is unavailable, open an issue containing only a request for a
private contact route. Wait for a private route before sharing sensitive details.

Reports are reviewed as time allows. Use the latest Community release where
possible. Release notes identify fixes and any required action.
