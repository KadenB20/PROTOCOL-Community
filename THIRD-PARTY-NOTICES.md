# Credits and third party notices

PROTOCOL uses open-source libraries and attributed reference content. Their
licences remain separate from the PROTOCOL Community licence. Each Windows release
includes a generated dependency notice with the exact shipped dependency versions
and available licence texts. The same dependency notice is also included with the
installed application under `resources/DEPENDENCY-LICENSES.txt`.

## Exercise reference

Exercise data by [RepDB](https://repdb.co), used under the RepDB Free Tier License.
The free snapshot and images may be used inside applications with attribution;
redistribution as a dataset or API is prohibited. Evaluation-only preview
animations are excluded. Individual exercise records retain source information.

Optional wger records and media retain their original source and licence details.
Their availability and licence terms depend on the selected source.

## Food reference

Canadian Nutrient File data is provided under the
[Open Government Licence Canada](https://open.canada.ca/en/open-government-licence-canada).
The bundled CNF attribution notice provides source and attribution details.

## Application libraries and fonts

The application uses Tauri, React, SQLite, and other libraries whose licences are
included in the release dependency notice. Inter is distributed under the SIL
Open Font License. Lucide icons are distributed under the ISC licence.
